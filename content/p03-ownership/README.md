# Part 3　オブジェクトと所有権

C++の核心です。オブジェクトがいつ作られ、誰が所有し、いつ壊されるかを理解します。

## 到達目標

- RAIIとスマートポインタを使って、所有権を説明できる
- コピーとムーブの違いを説明し、ムーブ専用の型を設計できる
- オブジェクトの寿命に関わる未定義動作を見抜ける
- 例外安全性の3つの保証レベルを説明し、コードに適用できる
