# Part 0　プログラミング入門

プログラミング未経験の人が、C++で最初の一歩を踏み出すためのPartです。

## 到達目標

- プログラムがどのように実行されるかを、CPU・メモリ・コンパイラという言葉を使って説明できる
- 変数・条件分岐・繰り返し・関数を使った小さなプログラムを、自分で書いて動かせる
- コンパイルエラーのメッセージを読み、自力で修正できる
- デバッガを使って、プログラムを1行ずつ実行しながら値を確かめられる
